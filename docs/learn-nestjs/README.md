# Learn NestJS with this project

A course that uses the real code in this repository, so every idea is attached to something you can open and run. Each lesson has: the idea in plain words, the real code, a mind map, a "how to read the error" section, questions and an exercise. Notes are written to be copied into Notion (the diagrams are Mermaid, which Notion supports in a code block; each also has a plain-text version).

How terms are written: the technical name first, then what it means in everyday language.
